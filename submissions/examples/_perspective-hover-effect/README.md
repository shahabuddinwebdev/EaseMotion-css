This contribution adds a Perspective Hover Effect to the submissions/examples/_perspective-hover-effect directory.

Included File:
1. demo.html
2. style.css
3. README.md

Features
🎯 3D perspective transformation
🌀 rotateX() + rotateY()
📦 transform-style: preserve-3d
💫 Floating/lift effect
🔮 Depth using translateZ()
🌑 Dynamic-looking shadow
Pure HTML + CSS
No JavaScript
